## 1. 双平台总览

| 维度 | 道理鱼（DoliFish Music） | 飞牛音乐（fnos） |

## 2. 道理鱼功能清单

### 2.1 登录与账号

- 账号密码登录（`POST /api/auth/login` → JWT），与 NAS 登录分离；`/api/v1/auth/media-access-status` 播放前校验（高频轮询）
- 开放注册开关（`/api/auth/registration-status`、`/api/admin/user-registration`）
- 多用户（管理员/普通用户），个人资料（`/api/auth/profile`）
- 客户端版本检测（`/api/client-version/latest`）+ APP 下载入口

### 2.2 曲库浏览

- **艺人**：网格/列表、分页、排序（最近添加/名称等）、统计信息；详情含艺人信息/专辑/歌曲
- **专辑**：网格/列表、分页、排序；详情含曲目列表、播放全部、加入队列、收藏
- **歌曲**：列表/网格、分页 + 游标加载、排序偏好**服务端持久化**（`/api/preferences/sorting`）；视图可切**目录浏览**（按文件夹）
- **歌单**：公开歌单 + 我的歌单；详情元信息 + 曲目分页；置顶/恢复默认排序/播放全部/随机播放/加入队列；系统歌单（喜欢的音乐等）
- **流派**：本地聚合（`/api` 无 genre 端点）
- **最近播放/播放历史**：`/api/library/playback-history/recent`
- **播放排行**：`/api/library/playback/top?period=week`

### 2.3 播放与转码

- 全局播放器：播放/暂停/上一首/下一首、队列（可清空）、**顺序/随机**、音量、进度拖动、当前曲目信息
- **服务端预取下一首**（`/api/player/prefetch`）
- **三条取流路径**（客户端按音质档位与能力选择）：
  | 路径 | 说明 |
  |---|---|
  | `/api/tracks/{id}/transcode` | 转码流（MP3 128~320 或 FLAC）；首次 200 实时管道，落缓存后 206 可随机定位（缓存 10GB / 7 天） |
  | `/api/tracks/{id}/stream` | 始终 206、支持 Range；服务端转封装为 AAC（非字节级直出） |
  | `/api/tracks/{id}/hls` | HLS VOD，3s 分片（`forceHls=1`），hls.js 按分片 Seek |
- 音质档位（前端内置）：`default 128k / high 192k / hq 256k / sq 320k / original 原始`；播放中切档保持位置
- 转码失败降级：`originalCompatible=1` 探测 → 记录位置 → 换兼容格式（AAC）重试 → 还原位置
- Seek：本地播放走 Range 定位（不向服务端传参）；**有声书额外上报进度**；转码失败重试自动还原位置

### 2.4 歌词

- 自研层 `GET /api/tracks/{id}/lyrics`：取 `effectiveCandidate.lyrics`（LRC **中英交错**）
-（Luobo 侧已适配：双键返回 + LRCLIB/网易云回退，见 `docs/歌词源优先级修复技术方案.md`）

### 2.5 推荐与探索（首页聚合）

- **每日推荐**（可刷新，`/api/library/recommendations/daily`）
- **心动歌单**（`/api/library/heart-playlists`）
- **精选推荐 / 此刻推荐 / 共享推荐**（场景化歌单，如「下班后的慢慢走」，共享推荐来自 `daoliyu-yuan`）
- **随机推荐**（`/api/tracks/random`）
- **最近添加**（专辑/艺人/歌曲/有声书/视频分区，带「查看更多」）、**最近播放**
- **本周播放排行**

### 2.6 收藏（六类）

歌曲、专辑、艺人、歌单、有声书、音乐视频——每类独立接口（`/api/favorites/*`）；收藏曲目 ID 集合用于列表内快速标注红心（`/api/favorites/tracks/ids`）；另设「收藏曲目 AI 偏好画像」接口。

### 2.7 搜索

统一搜索框，分类：**全部 / 歌曲 / 艺人 / 专辑 / 歌单 / 有声书 / 音乐视频**，各分类带条数统计，支持边输边搜（各实体接口均带 `search` 参数）。

### 2.8 有声书

- 独立模块（`/api/library/audiobooks`，分页/排序/搜索）
- **播放进度记录与续播**（`/api/library/audiobooks/progress`；`/play` 起播可带 `positionSeconds` 定位，`mode=fast`）
- 章节/选集：`/api/library/audiobooks/{id}/episodes`
-（Luobo 侧：章节播放走 Subsonic `/rest/stream?format=raw`，见 `docs/客户端接口与文档总览.md` §2.5）

### 2.9 音乐视频

- 视频列表（分页/排序/搜索）+ **视频歌单**；元数据懒加载（`metadataPriority=lazy`）

### 2.10 多端与输出

- **连接新客户端**（多设备/远端控制入口）
- **输出设备**：设备列表 / 切换输出设备 / 输出模式 / 循环模式 / 释放（`/api/player/output/*`）
- **远端控制**：`/api/player` 队列、`/seek`、`/volume`、`/prev`、`/next`；远端播放状态同步（`/api/player/output/status`）

### 2.11 个人中心

我的收藏六类汇总、我的歌单（含系统歌单）、最近播放/播放历史。

### 2.12 服务端管理（客户端不消费，仅列全貌）

- 多媒体库（概览/统计）、媒体管理（扫描路径、配额）、任务中心（含 `transcode_preprocess` 任务，可暂停/恢复/取消；扫描进度走 SSE）
- 用户管理（增删改查）
- 转码配置（总开关/格式/码率/HLS 码率/允许原始/DST 处理/缓存上限与 TTL）、转码统计、清理指定曲目转码缓存
- 元数据集成配置（Last.fm / AcoustID / MusicBrainz / Spotify / ListenBrainz）、共享元数据、补全状态
- 站点品牌（名称/Logo/主题）、菜单设置、界面设置、数据导出、清缓存、应用快照
- **点唱机（Jukebox）设置**：服务端存在该配置项（注：Luobo 客户端版已随功能整体删除，见 `docs/客户端接口与文档总览.md` §2.3 注）

### 2.13 接口要点速览

- 前缀 `/api` 返回 JSON；认证 `Authorization: Bearer <JWT>`（`POST /api/auth/login` 获取）
- **封面**：`/api/library/cover-tickets` 短期票据（约 2 分钟有效）→ `/api/cover?path=&size=`；兼容路径 `/api/v1/cover`、`/api/library/cover`；另有缩略图、外链图代理、静态资源
- 启动链路：`startup-status` → `bootstrap` → `profile` → `media-access-status` → `branding` → 聚合推荐 → 封面票据
- 播放链路：`POST /api/player/play` → 同步队列 → 预取 → 取流（stream/transcode/hls）→ 定期 `media-access-status`

### 2.14 未覆盖（采集限制）

写操作（新建/编辑/删除歌单、收藏写入、扫描触发、用户增删改、设置保存、快照、退出登录）未主动触发，确切方法与参数未记录——需要时基于前端产物静态分析（见 `~/Downloads/道理鱼-功能与接口清单.md` §六、§七）。

### 3.12 服务端协议（2026-10-20 APK 分析）

> **来源与取证**：`~/Downloads/FN_Music_1.0.3_00610141147.apk`（sha256 `8a429a8b…`，72.2 MB；Flutter AOT snapshot `1ce86630…`，Dart FullAOT kind 3；双 ABI 同 hash）。**三条通道交叉验证**：① rea `inspect_dart_aot` 提取 isolate 段字符串池（class-like tokens 2000/4000+，0-9/A-Z/a-i 段）；② `strings` 全量扫 `lib/arm64-v8a/libapp.so` 可打印串（URL 模板、路径分段、HTTP 头、字段名）；③ Web 端（`https://chengsitom.fnos.net/music/`）主 bundle `5e884898…-B563oObE.js` 静态分析——**接口方法与完整路径以 Web 端为准**（°3.12.3 表），APK 字符串池与之相互印证。注意：字符串池只是**字节模式观测**，方法（GET/POST）、请求体 schema 等无法从字符串直接判定——见 3.12.7。

**应用身份**：包名 `com.trim.fn_music`（播放服务 `com.trim.fn_music.playback`），Dart 包 `trim_music`（`packages/trim_music/` 资源路径），即 **TRIM 应用族**；Flutter + 原生混合（pigeon 插件 `trim_base_plugin` / `trim_common_plugin`，原生与 Flutter 路由互通 `PlatformRouter`）；本地 SQLite（sqflite）+ MMKV；服务端响应有本地缓存层（`[NasAPICacheStorage]` / `[NasJsonCacheMixin]`，缓存 key 形如 `_api@<时间戳>`）。播放器为 **ijkplayer 系**（自定义头 `X-TRIM-IJK-HTTP-Proxy`、`X-TRIM-IJK-Transcode-HLS`）。截图对应用户所见 V1.0.1，APK 为 1.0.3；「版本更新」在关于页（走 `/api/v1/check-update`）。

#### 3.12.1 连接与发现（FN Connect）

| 项 | 结论 |
|---|---|
| 服务器设置 | 域名/IPv4/IPv6 连接（`fn_connect_connect_info_link_type_domain/ipv4/ipv6`）；「测试地址」`fnConnectTestAddress` / `fn_connect_test_address` |

#### 3.12.2 鉴权

- **密码登录（Web 端实测）**：`POST /user/password-login`，请求体 `{username, password: sha256(明文密码), deviceId}`——客户端先 **sha256** 再发送（js-sha256），非明文；`deviceId` 为本地持久化 UUID（localStorage `device/id`）。APK 另有 `argon2` 相关字段（App 端哈希口径，与 Web 端是否一致待证）。
- **OAuth 登录（NAS 账号）**：`consumeOAuthCode` 流程——跳转 `{nasOAuth.url}/signin?client_id=<nasOAuth.clientId>&redirect_uri=/oauth/result&app_name=飞牛音乐` → 回调 `authLogin({code, deviceId})` → 返回 `{userToken, user}`。**实测 `GET /sys/config` 仅返回 `nasOAuth.clientId` 而无 `nasOAuth.url`**，Web 端点击「使用 NAS 登录」即抛 `oauthUrlMissing`（页面对应「授权登录流程异常」）——该环境的 OAuth 通道当前不可用。
- **令牌**：登录成功返回 `userToken`，客户端存储（`handleAuthenticatedUser` 写入）并经请求层携带；未带/失效返回 HTTP 401 + `code:99999 INVALID TOKEN`（`user/me` 实测）。
- 其他：请求签名 `sign` / `signature` / `signed` / `signingTime`、`sessionId`、`cookie`（`fn_connect_cookie`、`sharedCookiesEnabled`）、`userToken` / `fnos_token` / `access_token` / `clientId` / `clientSign` / `app_id` / `appversion` / `apiKey`（App 端与连接层）；多账号/登录设备管理（`account_login_device_*`）；退出登录 `user/logout`。

| 多端/输出设备 | ✅（连接新客户端/输出设备/远端控制） | ✅（FN Connect P2P/中继 + mDNS `_trim_music._tcp` 发现 + AirPlay/Google Cast 投送） | 均含投送 |
| 元数据写入 | ❓（服务端有刮削；写接口未采集） | ✅（客户端可写回：`track/metadata`、`artist/create`、`genre/create` 已确认） | **Luobo 已拍板只展示** |
| 多用户 | ✅（用户管理 + 注册开关） | ✅（用户管理 + 文件夹权限） | |
| 网络电台 | ❌（Subsonic 层不支持，客户端提示） | ❓（未见） | |

### 结论

1. **公共子集**（双平台都有的核心）：曲库四类浏览、搜索、收藏、歌单、播放队列/随机、音质选择、播放历史——Luobo 现有 Subsonic 抽象可覆盖。
2. **道理鱼独有**（飞牛不竞争）：推荐体系、有声书、视频、多端输出设备、服务端预取。
3. **飞牛独有**：元数据写回（已拍板不做）、离线缓存/已下载、多选批量（待确认）、OPUS 转码。
4. **待确认项**：飞牛歌词入口、多选、离线、投送；道理鱼 Web 端多选/离线。
