Luobo 有声书 · 无封面形态设计稿 v1

默认「永远没有封面」：书库改行式书架（不做封面墙），书封改为纯文字装帧（低饱和底色 + 书名排版 + 书脊 / 内框 / 小字）。章节页套全站 hero 骨架，底部常驻听书控制条（±15 秒 / 倍速 / 定时）。
筛选 chip 的展现逻辑：不是上滑才出现——进页面就在进度条下方；向下滚动时随内容上移，到顶栏下沿（状态栏 + 56）停住吸顶，一直可见到页底。只有一个实例，不做"头部一份 + 吸顶再一份"。
第 5 屏是章节页向下滚动后的状态（不是独立页面，无新入口）：头部滚走、chip 行已吸顶、返回圆钮长成「返回 + 书名」胶囊。
