## 3. 飞牛对标结论（逐弹窗规格）

**通用骨架**：底部升起，顶部圆角 20 + 拖拽把手 36×4，遮罩 `rgba(0,0,0,.42)`；深色灰底/浅色白底；玫红 `#F0305C` 仅用于选中/危险/强调，不做大面积填充。

- **歌曲 `⋮` 更多菜单（4 变体，按调用来源裁条目）**
  - 顶部上下文头：圆角封面 + 歌名 + 灰字歌手。
  - 变体 A（列表页/首页）：主操作**横排 3 方块**（播放 / 下一首播放 / 加入播放列表）→ 竖列：专辑｜歌手｜下载｜**收藏♡**｜添加到歌单｜歌曲信息（只读）。
  - 变体 B（播放页）：**无横排、无收藏** → 竖列：专辑｜歌手｜下载｜添加到歌单｜歌曲信息（只读）。
  - 变体 C（歌单内）：同 A，**多一项「从当前歌单移除」**（置于「添加到歌单」之后），末项为「歌曲信息（只读）」。
  - 变体 D（最近播放 / 播放历史，2026-10-23）：同 A 但**无「收藏♡」行**。fnos 该来源变体此处是「**从最近播放中移除**」（帧 v5_0112），但本仓库服务端**没有删历史的接口** → 移除项暂不提供，只做「去掉收藏行」（用户 2026-10-23：「播放历史列表的更多面板，不应该有从喜欢的歌曲中移除」）。**✅ 已实施（2026-10-23）**：`SongMenuContext.history` 入枚举，`history_screen` 歌曲行显式传入（该页同批已套 C6 hero 头）。
  - ⚠️ **「歌曲信息」做成只读**：保留 ⋮ 菜单入口，点开是**只读**信息卡（§4.8）；飞牛 `06` 的**编辑**能力（歌曲信息编辑 + 修改歌手/修改风格选择器 + 封面回写）依赖其自家库写标签，Luobo 后端无写标签接口 → **不做编辑**，只展示（见 §5）。
- **确认弹窗**：底部升起短卡；居中标题 + 居中灰字说明 + 底部**左右双胶囊**（取消=灰底 / 危险=玫红实心）。
- **添加到歌单**：拖拽把手；首项「**新建歌单**」（玫红圆底+图标）+ 已有歌单（**封面缩略图** + 名 + 灰字「N 首」）。
- **歌单设置 `···`**：**胶囊叠**（非圆角块列表）。飞牛原含 编辑/清除失效歌曲/删除/取消；Luobo 落地为 **编辑（普通灰底）→ 删除（淡红底红字）→ 取消**（「清除失效歌曲」因后端无能力本期挂起，见 §4.4/§5）。
- **多选模式**：**整屏接管**（不是浮层）。顶栏：拖拽把手 + 玫红圆「−」+「已选 N 首」+「完成」；行左**圆形选择框**（选中=玫红实心✓）；底部 **4 等分操作栏**（播放 / 加入播放列表 / 下载 / 添加到歌单）。
- ~~**视图切换**：列表页「共 N 首」行右侧，列表/网格图标切换。~~ **已证伪（2026-10-21）**：飞牛右上角只有排序；专辑固定网格，歌曲/歌手/风格固定列表，**不做切换**。
- **排序浮层**：锚定毛玻璃；玫红勾 + 仅选中项方向箭头。

## 4. 设计方案（逐弹窗）

### 4.1 歌曲 `⋮` 菜单 —— 重构为 4 变体

- 新增枚举 `SongMenuContext { list, player, playlist, history }`，由调用方传入（`SongTile` 增加 `menuContext` 参数，默认 `list`）。
- `_SongOptionsSheet` 改为按 `menuContext` 组装：
  - 顶部横排主操作：`list`/`playlist`/`history` 显示「播放 / 下一首播放 / 加入播放列表」；`player` 不显示。
  - 收藏行：**仅 `list`**（`player` 与 `history` 均不显示；`playlist` 自 2026-10-22 起也不显示）。
  - 「从当前歌单移除」：仅 `playlist`，需调用方透传 `onRemoveFromPlaylist`。
- 迁移：`showGlassBottomSheet` → `showLuoboSheet`（统一走 `LuoboSheetShell`，符合其「5 种浮层共用外壳」注释）。
- **砍掉「评分」**：用户确认评分功能无用，本次直接移除——从 `⋮` 菜单删除评分项（`song_tile.dart:612`）并删除 `_showRatingDialog`（`song_tile.dart:777-835`）及相关调用；核对评分字段是否还有其他入口/展示点，一并清理，避免留死代码。
- **「歌曲信息」做成只读**（用户 2026-10-20 定）：⋮ 菜单**保留**「歌曲信息」入口（三变体末项），点开是**只读**信息卡（规格见 §4.8）。飞牛 `06` 的**编辑**部分（歌曲信息编辑页 + 修改歌手/修改风格选择器 + 封面回写）依赖其自家库写标签，Luobo 后端无写标签接口 → **编辑/选择器一律不做**，信息卡只展示不回写。
- 新建组件 `LuoboActionGrid`（横排 3 方块），放 `lib/widgets/luobo/`。

### 4.2 确认弹窗 —— 新建 `LuoboConfirmSheet`

- 在 `luobo/sheet_shell.dart` 旁新增 `showLuoboConfirmSheet({title, message, confirmLabel, danger})`，返回 `bool`。
- 结构：`LuoboSheetShell`（**居中标题 + `showHandle:false`** —— 飞牛确认卡无拖拽把手）+ 灰字说明 + `Row` 双胶囊（取消 `pillFill` / 确认 `accent`）。
- 替换现有三处 `AlertDialog`（移除歌曲 / 批量移除 / 删除下载），删除歌单也接入。

### 4.3 添加到歌单 —— 补「新建歌单」+ 封面

- `song_tile.dart:959` 的选择器首行插入「新建歌单」（玫红圆底 + `AppIcons.add`），点击走现有建单流程（复用 `playlists_screen` 的建单弹窗逻辑，抽成 `showCreatePlaylistSheet`）。
- 已有歌单行用封面缩略图替换 `queue_music_rounded`（无封面回退到玫红圆底图标）。

### 4.4 歌单设置 —— 胶囊叠（编辑=改名 only）

- `playlists_screen.dart` 行尾增加 `···` 圆钮触发（保留长按作为兼容入口）。
- 面板用**胶囊叠**：编辑 / 删除（danger）/ 取消。
- 「编辑」**只做改名**（模态表单，复用建单表单范式）——改封面后端不支持回写，不做。
- 「清除失效歌曲」**本期挂起**：服务层无「识别失效项」能力（见 §5），面板不出该项；待后端补齐再加。

### 4.5 多选模式 —— 整屏接管壳 + 扩展到 all_songs

- 新建 `MultiSelectScaffold`（或在 `all_songs_screen`/`playlist_screen` 共用的 mixin）：顶栏（把手+玫红圆「−」+「已选 N 首」+完成）+ 底部 4 等分操作栏。
- 行左圆形选择框（选中玫红实心✓）取代现有 `CheckboxListTile`。
- `all_songs_screen` 接入多选（长按进入）；批量操作：播放 / 加入播放列表 / 下载 / 添加到歌单。
- `playlist_screen` 现有多选重构到同一壳，保留「移除」能力。

### 4.6 ~~视图切换~~（已取消，2026-10-21）

- **不做**。飞牛没有列表/网格切换：专辑固定网格，歌曲/歌手/风格固定列表；右上角只有排序。原计划中的 `ViewModeProvider` / 切换图标一并取消。

### 4.7 排序浮层

- 已达标。仅核对飞牛各列表的排序项是否齐（专辑/歌手/风格列表的字段集），差的补枚举，不改组件。

### 4.8 歌曲信息（只读信息卡）

- `⋮` 菜单「歌曲信息」的落点：**只读** sheet（复用 `LuoboSheetShell`，可滚动）或独立只读页。**无输入框、无保存按钮、无修改歌手/风格选择器。**
- 内容：顶部大封面 + 歌名/歌手；技术参数横排卡（码率 / 采样率 / 声道 / 格式，数据取自现有 `Song` 模型与播放源，⋮ 头部已展示音质可复用）；只读信息行（专辑 / 年份 / 曲目序号 / 光盘序号 / 风格 / 文件路径），用 label+value 竖排（`LuoboSheetRow` 只读形态）。
- 字段缺省时**整行隐藏**，不显示空值。
- ⚠️ 入口在一期菜单里 → **只读卡随一期一起出**，避免死入口。

## 5. 数据契约 / 能力依赖

逐项标注后端是否已支持（已核对 `lib/services/` 服务层写接口：仅 `createPlaylist` / `deletePlaylist` / `updatePlaylist` / `star` / `unstar` / `scrobble`，无任何写标签接口）：
- 从歌单移除单曲 / 批量移除：`updatePlaylist`（现有 `playlist_screen` 已用，可复用）。✅
- 新建歌单 / 歌单改名：`createPlaylist` / `updatePlaylist` 支持。✅ **改封面不支持回写 → 不做。**
- **编辑歌曲元数据（名称/歌手/专辑/年份/风格等）：服务层无 `editSong`/`updateSong`/`updateTags` 任何接口 → 飞牛独有，Luobo 不做编辑。** 「歌曲信息」改做**只读**展示（§4.8），数据来自现有 `Song` 模型/播放源，不回写。
- **清除失效歌曲：服务层无「识别失效项」能力 → 本期挂起**，歌单设置面板不出该项。
- 批量下载 / 批量加入播放列表：复用单曲能力循环，注意并发与失败聚合提示。✅

## 6. 退化与安全阀

- 变体裁剪必须**按来源显式传入**，不靠运行时猜；缺参数时退回变体 A（最全），避免漏项。
- 确认 sheet 必须走 **root navigator**（同 `showLuoboSheet` 注释），否则播放条/底栏会压在浮层上。
- 多选整屏接管进入/退出要保证返回键、完成、空选态的一致处理；批量操作失败要聚合提示而非逐条弹。
- 不碰 `applicationId` 等原生标识；不动排序组件既有实测值。

## 7. 测试与验收（真机清单）

## 9. 排版规格（字号/字阶/尺寸 —— 复用设置页已实测 Token）

> 原则：**不新造字号/间距/圆角**，一律引 `theme/design_tokens.dart` 与设置页已落地的公共组件。这样弹窗字号自动与设置页（及飞牛实测）一致。

**可直接复用（已实测，与设置页同款）**：
- Sheet 居中标题：`LuoboSheetShell.title` → `navTitle.copyWith(15)` = **15dp / w600**。
