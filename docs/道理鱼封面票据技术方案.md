## 1. 实测结论

### 1.1 专辑封面票据（按专辑申请）

```
POST /api/library/cover-ticket            （单数！不是 cover-tickets）
Authorization: Bearer <JWT>
Content-Type: application/json
{"albumId": "alb_..."}

200 OK
{"expiresAt":"2026-08-07T06:58:20Z","expiresInSeconds":120,
 "ticket":"<短时票>","url":"/api/cover?albumId=alb_...&ticket=..."}
```

- 有效期 **120s**；body 只认 `albumId`，其它值 → `INVALID_COVER_TARGET`
- 取图：`GET {url}&size=600`，**仍需 JWT**（只带 ticket 不带 JWT → 401）
- 响应头 `Cache-Control: private, max-age=0, must-revalidate` → **不能长期缓存**

### 1.2 艺人封面（不需要票据）

`GET /api/library/artists` 的条目里直接带：

```json
{"id":"art_...","name":"...","coverArtPath":"system/covers/xxx.jpg",
 "coverArtUrl":"/api/cover?path=system%2Fcovers%2Fxxx.jpg","coverArt":"/api/cover?path=..."}
```

即艺人封面是 **path 式** `/api/cover?path=...`（相册/曲目同理），不涉及 albumId 票据。

### 1.3 与 Subsonic 兼容层的关系

| 方式 | URL | 缓存 | 认证 |
|---|---|---|---|
| Subsonic `getCoverArt` | `/rest/getCoverArt?id=album:alb_...` | 1 天 | 明文 u/p |
| 自研 ticket | `POST cover-ticket` → `/api/cover?albumId=&ticket=` | 不缓存 | JWT |
| 自研 path | `/api/cover?path=...` | — | JWT（推测，待真机确认） |

Luobo 目前**专辑/歌曲封面继续用 Subsonic 兼容层**（可用、缓存友好），本轮只解决「艺人头像」。

## 2. 实现

`lib/services/subsonic_service.dart`：

- `parseAlbumCoverTicket(data, now)`（纯函数）：解析 `{ticket,url,expiresAt,expiresInSeconds}`；
  过期时间早于 now 时给 **30s** 缓冲。**按 albumId 缓存**，过期前 15s 刷新，并发去重。
- `daoliyuAlbumCoverUrl(albumId, size)`：同步取缓存票据拼绝对 URL；未就绪返回 null 并后台申请
  （调用方回退 Subsonic，无回归）。**本轮未接线到 UI**，留给「专辑封面切原生」时用。
- `prefetchDaoliyuArtistCovers()`：登录后拉一次 `GET /api/library/artists?take=1000`，
  用 `parseArtistCoverPaths` 建 `artistId → coverArtPath` 内存缓存。
- `daoliyuArtistCoverUrl(artistId, size)`：同步返回 `/api/cover?path=...&size=`；
  未命中时后台补拉并返回 null。

`lib/providers/library_provider.dart`：`resolveArtistCover` 新增**级 0**——道理鱼优先用
`daoliyuArtistCoverUrl`，失败回退 `artistImageUrl → coverArt → 专辑封面 → 2×2 拼贴 → 首字母`。

## 3. 风险与待确认

- `/api/cover?path=` 是否**必须带 JWT**未实测；`CachedNetworkImage` 默认不带 header。
  若真机 401 → 现象是艺人头像不显示并回退专辑封面（不崩），届时需要给图片请求加
  `httpHeaders: {'Authorization': 'Bearer ...'}`（`AlbumArtwork` 统一加）。
- `GET /api/library/artists` 实际参数是 `take` 还是 `limit`（抓包用的是 `limit=2`，接口清单写 `take`）：
  当前用 `take=1000`；若服务端不认，预取会为空 → 行为等同改动前（回退）。
- 专辑/歌曲封面切原生 tick + 不缓存策略（`max-age=0`）会明显增加流量，暂不做。
