# 道理鱼封面 / 票据技术方案（2026-10-23，已按实测抓包修正）

> 一手素材：`~/Downloads/道理鱼接口/道理鱼接口文档.md` §6 + `道理鱼_接口素材/captures/api_cover_ticket.txt`
> （真实 request/response 抓包；此前的「接口清单」只写了用途、没写结构，导致第一版实现按猜测写错。）

## 1. 实测结论

### 1.1 专辑封面票据（按专辑申请）

```
POST /api/library/cover-ticket            （单数！不是 cover-tickets）
Authorization: Bearer <JWT>
Content-Type: application/json
{"albumId": "alb_..."}

200 OK
{"expiresAt":"2026-08-07T06:58:20Z","expiresInSeconds":120,
 "ticket":"<短时票>","url":"/api/cover?albumId=alb_...&ticket=..."}
```

- 有效期 **120s**；body 只认 `albumId`，其它值 → `INVALID_COVER_TARGET`
- 取图：`GET {url}&size=600`，**仍需 JWT**（只带 ticket 不带 JWT → 401）
- 响应头 `Cache-Control: private, max-age=0, must-revalidate` → **不能长期缓存**

### 1.2 艺人封面（**不需要票据，也不需要 `/api/cover`**）

两张抓包对照：

- `sub_getArtists.txt`：Subsonic 兼容层的 artist 条目自带
  `"coverArt": "artist:art_2671b89ae03e1f02"`（**id 与 `/api` 层一致**）
- `sub_getCoverArt.txt`：`GET /rest/getCoverArt?id=album:alb_...` 返回
  `Cache-Control: public, max-age=86400`（1 天）

所以艺人头像**最省事的正解**是走 Subsonic 兼容层：

```
GET /rest/getCoverArt?id=artist:art_xxx&size=300&u=&p=
```

一天缓存、u/p 认证、无 JWT、无票据。`/api/library/artists` 的 `coverArtPath`
只是另一条等价路径（`/api/cover?path=`），没有额外收益。

### 1.3 与 Subsonic 兼容层的关系

| 方式 | URL | 缓存 | 认证 |
|---|---|---|---|
| Subsonic `getCoverArt` | `/rest/getCoverArt?id=album:alb_...` | 1 天 | 明文 u/p |
| 自研 ticket | `POST cover-ticket` → `/api/cover?albumId=&ticket=` | 不缓存 | JWT |
| 自研 path | `/api/cover?path=...` | — | JWT（推测，待真机确认） |

Luobo 目前**专辑/歌曲封面继续用 Subsonic 兼容层**（可用、缓存友好），本轮只解决「艺人头像」。

## 2. 实现

`lib/services/subsonic_service.dart`：

- `parseAlbumCoverTicket(data, now)`（纯函数）：解析 `{ticket,url,expiresAt,expiresInSeconds}`；
  过期时间早于 now 时给 **30s** 缓冲。**按 albumId 缓存**，过期前 15s 刷新，并发去重。
- `daoliyuAlbumCoverUrl(albumId, size)`：同步取缓存票据拼绝对 URL；未就绪返回 null 并后台申请
  （调用方回退 Subsonic，无回归）。**本轮未接线到 UI**，留给「专辑封面切原生」时用。
- ~~`prefetchDaoliyuArtistCovers` / `daoliyuArtistCoverUrl`~~ **已删除**：
  艺人封面改用 Subsonic `artist:<id>`（见 §1.2），不需要预取。

`lib/providers/library_provider.dart`：`resolveArtistCover` 新增**级 2.5**——道理鱼下若
artist 没有 `coverArt`，用 `artist:<id>` 合成 Subsonic 封面 URL；再失败才回退
`专辑封面 → 2×2 拼贴 → 首字母`。

## 3. 风险与待确认

- ~~`/api/cover?path=` 是否必须带 JWT~~ **不再需要**：艺人封面走 Subsonic 兼容层。
- 专辑/歌曲封面切原生 ticket（`max-age=0`）会明显增加流量，**暂不做**；
  `daoliyuAlbumCoverUrl` 作为预留接口保留（已单测）。
- `GET /api/library/artists` 的参数在抓包里是 `limit`（接口清单写 `take`）—— 该请求已不需要。

## 5. 艺人统计（2026-10-23 追加）

抓包 `api_artists.body` 显示 `GET /api/library/artists` 的每个条目自带
**`trackCount` / `albumCount`**（30 个条目全有）——这是「N 首歌 · M 张专辑」的权威值。

实现：

- `prefetchDaoliyuArtistStats()`：登录后拉一次 `/api/library/artists?limit=1000`，
  用 `parseArtistStats`（纯函数 + 单测）建 `artistId → (trackCount, albumCount)` 内存缓存；
- `LibraryProvider.daoliyuArtistTrackCounts / daoliyuArtistAlbumCounts` 暴露给 UI；
- `utils/artist_stats.dart`：**服务端值优先**，没有才回退四口径启发式
  （artistId / 歌手名含合唱拆分 / 专辑 songCount 累加 / 按名字累加）。

效果：歌手列表的「N 首歌」与「按歌曲数排序」在道理鱼下变成准确值；非道理鱼不受影响。
