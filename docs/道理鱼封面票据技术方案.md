# 道理鱼封面票据（cover-tickets）技术方案（2026-10-23）

> 背景：道理鱼的封面接口是**原生** `GET /api/cover`，需要**短期票据**（`/api/library/cover-tickets`，约 2 分钟）。
> Luobo 之前一律走 Subsonic 兼容层 `getCoverArt?id=album:<id>`；**艺人头像**因此拿不到「艺人本人图」，只能退到专辑封面/拼贴。

## 1. 接口与约束（来自《道理鱼-功能与接口清单.md》§2/§9）

| 接口 | 说明 |
|---|---|
| `GET/POST /api/library/cover-tickets` | 申请封面票据；响应结构**未公开**（清单只写了用途） |
| `GET /api/cover?path=\|artistId=&size=&ticket=` | 按路径或**艺人 ID** 取封面，sizes 如 100/300 |

⚠️ 票据约 2 分钟过期；过期后需重新申请。

## 2. 实现（本轮）

`lib/services/subsonic_service.dart`：

1. **`parseCoverTicketPayload(data, now)`**（纯函数，可单测）：防御式解析
   - `{ticket, exp|expiresAt|expiresIn}`；
   - `{tickets|items: [字符串]}`；
   - `{tickets: [{ticket|value|token, exp|expiresAt|expiresIn}]}`；
   - `exp` 兼容 秒/毫秒时间戳、剩余秒数、ISO 字符串；解析不到有效期按 **100s**；
   - 已过期时给 **30s** 缓冲（避免无限刷新）。
2. **`ensureCoverTicket()`**：缓存 + 过期前 15s 刷新 + 并发去重；登录成功后**预取一次**（`ensureCoverTicket().ignore()`）。
3. **`daoliyuCoverUrl({path, artistId, size})`**：**同步**返回 `/api/cover?...`；
   - 票据已缓存 → 带上 `ticket`；
   - 未缓存 → 返回无票 URL 并后台补一张（下一次渲染/重试即有票）。
4. **`LibraryProvider.resolveArtistCover` 新增「级 0」**：道理鱼下优先用
   `daoliyuCoverUrl(artistId: artist.id)`，失败再落到原有链路
   （artistImageUrl → coverArt → 专辑封面 → 拼贴 → 首字母）。

## 3. 降级与风险

- 票据拿不到 / 结构不符 → `ticket=null`，行为与改动前**完全一致**（无回归）；
- 无票 URL 大概率 401 → 艺人头像回退到专辑封面/拼贴/首字母；
- 专辑/歌曲封面**仍走 Subsonic 兼容层**（`album:<id>`），本轮不动：
  - 原生 `path` 式封面留待「服务端确认票据稳定」后再切；
  - 顺带可把 `/api/library/artists?includeStats` 的统计接进来，替代本地估算的「N 首歌」。

## 4. 验证

- 单测：`test/services/cover_ticket_test.dart`（7 条，覆盖五种响应形态 + 过期 + 非法）。
- **需要真机/真服务器验收**：道理鱼账号下打开歌手列表，头像应为**艺人图**而非专辑封面；断网/票据失败时应回退且不崩。
