# Luobo 客户端接口与文档总览

> 状态：整理完成（2026-08-07）
> 范围：Luobo（原 Musly）Flutter 客户端对外发起的所有网络接口清单，逐条对照 Navidrome 服务端实现；并索引 `docs/` 目录全部技术文档。
> 依据：`lib/services/` 各服务源码（当前 master `c889513` v1.1.12）+ `docs/navidrome-服务端技术文档.md` + `docs/ultrasonic客户端技术文档.md`

## 1. 接口全景

Luobo 客户端是一个多协议音乐播放器，对外接口按"服务器族 + 外部依赖"划分：

| # | 协议 / 对端 | 客户端实现 | 用途 | 说明 |
|---|---|---|---|---|
| 1 | **Subsonic / OpenSubsonic** | `lib/services/subsonic_service.dart` | 主服务器（Navidrome 等） | 全部库浏览/播放/收藏/歌单/歌词/电台 |
| 2 | **道理鱼 /api 层（JWT）** | `lib/services/subsonic_service.dart` | 道理鱼服务器族补充 | `serverFamily='daoliyu'`：歌词/随机歌走自研层（见 `docs/道理鱼接入技术方案.md`） |
| 2 | **Jellyfin / Emby** | `lib/services/jellyfin_service.dart` | 服务器族 `jellyfin` | 同一套 UI 抽象之上的 Jellyfin REST 适配 |
| 3 | **LRCLIB** | `lib/services/lrclib_service.dart` | 歌词回退源 ① | `https://lrclib.net/api` |
| 4 | **网易云音乐** | `lib/services/netease_lyrics_service.dart` | 歌词回退源 ② | `https://music.163.com/api`（中文歌覆盖补充） |
| 5 | **YouTube Music** | `lib/services/youtube_service.dart` | YouTube 模式 | 经 `youtube_explode_dart` 库（manifest/搜索/歌单/相关视频） |
| 6 | **DeepSeek（OpenAI 兼容）** | `lib/services/ai_playlist_service.dart` | AI 歌单 + 知识库打标 | `POST {base}/chat/completions`，默认 `https://api.deepseek.com` |
| 7 | **GitHub Releases** | `lib/services/update_service.dart` | 更新检查 | `api.github.com/repos/chengsitom/Luobo/releases/latest` |
| 8 | **UPnP / DLNA** | `lib/services/upnp_service.dart` | 局域网投送 | SSDP 发现 + SOAP AVTransport/RenderingControl |
| 9 | **Chromecast** | `lib/services/cast_service.dart` | 局域网投送 | Google Cast SDK（`google_cast` 插件） |
| 10 | 离线下载 | `lib/services/offline_service.dart` | 本地缓存 | 复用 `getStreamUrl`/封面 URL 经 Dio 落盘 |
| 11 | 诊断打点 | `lib/services/diagnostics/network_interceptor.dart` | 网络指标 | 所有 Dio 请求耗时/状态采集 + URL 脱敏 |

> 服务器族切换：`ServerConfig.serverFamily`（`subsonic` 默认 / `jellyfin`），见 `lib/models/server_config.dart:36`。`SubsonicService.configure()` 按族实例化对应的适配服务，对外暴露统一的 `SubsonicService` 方法面（`lib/services/subsonic_service.dart:60-82`）。

## 2. Subsonic API（Navidrome 主对接）

### 2.1 认证与公共参数

- 每个请求固定携带：`u=<用户名> & v=1.16.1 & c=Musly & f=json`（`_getAuthParams`，`subsonic_service.dart:355-376`）；
- **token+salt（默认）**：`t = md5(password + s)`，`s` 为随机 8 位（UUID v4 前 8 字符）；与 Navidrome `validateCredentials` token 分支算法一致（`navidrome-服务端技术文档.md` §4.1）；
- **明文（legacy）**：`useLegacyAuth=true` 时改带 `p=<密码>`；
- **封面 URL 专用稳定 salt**：`_stableAuthParams` 固定 `s=musly_stable`，保证同一服务器/账号的封面 URL 长期不变，命中 Navidrome 磁盘缩略图缓存（`subsonic_service.dart:378-401`，对照 §5.3 getCoverArt 缓存键规则）；
- 额外公共参数：`musicFolderId`（配置了多库时取第一个，`subsonic_service.dart:411-413`）。

### 2.2 LAN/远程双地址

- `resolveActiveUrl({forceProbe})`：先探测局域网 URL（3s 超时 `ping`），不可达则回退远程地址；上次会话停在远程时冷启跳过阻塞探测、后台静默切换（`subsonic_service.dart:104-210`）；
- 探测结果持久化到 SharedPreferences（`last_active_base_url`）；
- 生效地址变化通过 `onActiveUrlChanged` 通知转码服务刷新 LAN 覆盖（`subsonic_service.dart:38-41`）。

### 2.4 错误处理约定（`_request`，425-480）

- 超时 → "Connection timed out. Check your server URL."；
- 连接失败含 SSL 关键字 → 提示开启自签名证书；`401/403` → 用户名或密码错误；`404` → URL 路径错误；`>=500` → 服务端错误；
- `subsonic-response.status != "ok"` → 抛 `error.message`。

## 3. 歌词取源链（5 级）

客户端歌词加载顺序（`lib/services/lyrics/lyrics_source.dart` 为**唯一实现**，见 `docs/歌词源优先级修复技术方案.md` §4.1 / §5.3）：

1. **离线歌词缓存**（本地，`<songId>.lyrics.json`）—— 缓存顶层带 `v` / `source` 来源标记（2026-10-08 新增）：
   - `source ∈ {daoliyu, server}` → **直接用，零网络**；
   - `source ∈ {lrclib, netease}` 或旧缓存无标记 → **每进程每首复查一次**服务器，命中则覆盖缓存；复查无果**不删缓存**（离线安全）；
2. **道理鱼自研歌词**（`serverFamily='daoliyu'` 时优先，`getLyricsBySongId` 内部）：`GET /api/tracks/{id}/lyrics` 取 `effectiveCandidate.lyrics`（LRC 含中英交错）→ **双键返回** `{lyrics, structuredLyrics}`；
3. **Subsonic `getLyricsBySongId`**（Navidrome structuredLyrics，含 enhanced cue）→ 与 4. **Subsonic `getLyrics(artist, title)`**（普通歌词接口）；
5. **LRCLIB**：`GET https://lrclib.net/api/get?artist_name=&track_name=&duration=`（`lrclib_service.dart:32-38`），syncedLyrics 优先，否则 plainLyrics，返回 Subsonic 兼容的 `structuredLyrics` / `{value}` 结构；
6. **网易云音乐**：`POST https://music.163.com/api/search/get`（`s=<artist title>&type=1&limit=5&offset=0`，`netease_lyrics_service.dart:75-79`）→ `GET /api/song/lyric?id=&lv=1&tv=1`（125-131），LRC 解析后同样转 Subsonic structured 结构；Referer/UA 伪装浏览器头。

> ① 全部形状归一化在 `lib/services/lyrics/lyrics_source.dart` 的 `extractLyricsText()` 内完成：同时兼容 `{start, value}`（Subsonic）与 `{startTicks, text}`（Jellyfin），消除此前「同一份响应两条链各解析出空行」的问题（§2.6b）。
> ② 纯文本（无时间轴）歌词进车机链时合成静态单行 LRC（§5.5 选项 A）。
> ③ LRCLIB 与网易云回退开关：`getLrcLibFallback` / `getNeteaseFallback`（`storage_service.dart:157-175`），默认分别 关 / 开。

## 5. YouTube Music 模式

`SubsonicService` 暴露统一方法面，内部路由到 `YoutubeService`（`youtube_service.dart`）：

- **连通性**：`GET https://music.youtube.com/`（`pingWithError`，117）；
- **封面**：`https://img.youtube.com/vi/{videoId}/mqdefault.jpg`（135）；
- **音频流**：`youtube_explode_dart` `videos.streamsClient.getManifest`（mweb → 默认 android → androidMusic 客户端依次尝试），自实现 `_YoutubeStreamAudioSource` 用 `package:http` 代理 Range 请求规避 ExoPlayer 403（22-92）；流 URL 缓存 5h（`_streamCacheMaxAge`，101）；
- **搜索/随机**：`yt.search.search(query, filter: video)`；
- **歌单**：`yt.playlists.get` / `getVideos`（取前 200）；
- **相关视频**：`yt.videos.getRelatedVideos`；
- **艺人热门**：`yt.channels.get` + search；
- **不支持项**：创建/编辑/删除歌单、收藏、scrobble 均为 no-op 或抛 `UnsupportedError`（匿名模式，237-263、294-299）。

> 注：`configure()` 中 YouTube 分支目前被注释（`subsonic_service.dart:68-70`），YouTube 模式处于保留但未启用状态。

## 6. DeepSeek AI（AI 歌单 + 知识库打标）

`lib/services/ai_playlist_service.dart`：

- **端点**：`POST {aiBaseUrl}/chat/completions`，默认 `https://api.deepseek.com`（`storage_service.dart:216`）；`Authorization: Bearer <key>`；
- **模型**：默认 `deepseek-v4-flash`（`storage_service.dart:236`）；**`thinking: {type: disabled}`** 显式关闭思考模式（V4 默认开启，会烧光 max_tokens 导致 content 空，见记忆 `reference_deepseek_docs.md`）；
- **批量打标**（`generateKnowledge`）：50 首/批，`temperature=0.3, max_tokens=4000`，输出 `序号|标签1,标签2,…`；连续 3 批解析失败熔断（`_maxConsecutiveFailures=3`，29）；每批落盘支持中断续跑；
- **AI 歌单**（`generatePlaylist`）：`temperature=0.7, max_tokens=2000, response_format={type: json_object}`，输入含用户画像（常听歌手/风格/完播/跳过/高评分/时段）+ 候选歌曲标签列表，返回歌曲 ID JSON 数组；
- 结果经 `SongKnowledgeCache` 本地持久化（`song_knowledge.json` + `knowledge_progress.json`）。

## 8. 局域网投送（UPnP / Chromecast）

### 8.1 UPnP / DLNA（`lib/services/upnp_service.dart`）

- **发现**：SSDP `M-SEARCH * HTTP/1.1` 组播（239.255.255.250:1900），解析响应 `LOCATION`（108）；
- **设备描述**：`GET <location>` 抓 XML，筛选 `AVTransport:1` 与 `RenderingControl:1` 服务（205-228）；
- **控制**：`POST <controlURL>`，`SOAPAction: "urn:schemas-upnp-org:service:AVTransport:1#<action>"`，动作含 Play/Pause/Stop/Seek/SetAVTransportURI 等（550-683）。

### 8.2 Chromecast（`lib/services/cast_service.dart`）

- 基于 `google_cast` 插件；`_mimeTypeFromUrl` 按扩展名映射 audio/flac、ogg/opus、mp4、mpeg 等（297-307）；经 `mediaLoad` 投送 URL（234-266）。

## 10. 网络诊断与日志

- **统一拦截器** `networkMetricsInterceptor`（`diagnostics/network_interceptor.dart:26-87`）：所有 Dio 请求记录 `→/← method url status ms`，聚合进 `MetricsCollector.networkRequest` 并落 `requestTiming` 事件；
- **URL 脱敏** `sanitizeQueryUrl`：Subsonic 认证参数 `p/t/s` 打码为 `***` 后才写日志（8-19）；
- 客户端日志前缀 `[Musly] →/← …`（`subsonic_service.dart:55-58` 的 `logLine`），可与 Navidrome 服务端日志对照排查（见 `navidrome-服务端技术文档.md` §14）。

## 12. 客户端 ↔ Navidrome 服务端对照要点（承接 navidrome 文档 §15）

| 客户端行为 | 服务端对应 | 备注 |
|---|---|---|
| `t/s` token+salt（随机 8 位） | `validateCredentials` token 分支 `md5(password+salt)` | salt 不校验格式 |
| 封面稳定 salt `musly_stable` + 统一 `size=600` | 缩略图缓存键含 size，10 年强缓存 | URL 稳定才命中缓存 |
| `stream` + `estimateContentLength=true` | `EstimatedContentLength = duration×bitrate/8×1024` | 转码流可估计时长/拖动（#170） |
| `scrobble` start/finish（失败入离线队列补发） | PlayTracker 会话 + `incPlay` + buffered scrobbler | 429/网络抖动不丢播放记录 |
| `star/unstar/setRating/getStarred2` | `annotation` 表 + `average_rating` 重算 + RefreshResource 广播 | 多端同步 |
| `search3` | FTS5/bm25，CJK 自动 LIKE | — |
| `getLyricsBySongId` | structuredLyrics（含 enhanced cue） | 客户端三级回退 |
| `updatePlaylist` 重复 `songIdToAdd` 键 | `p.Strings("songIdToAdd")` 多值解析 | Navidrome 不识别 `[i]` 下标形式 |
| LAN/远程双地址探测（3s ping） | 无特殊处理 | 客户端 `resolveActiveUrl`，冷启跳过/后台切换 |
| 转码流 429 `Retry-After` | `ErrorTooManyTranscodes`（`TranscodeLimiter`） | 客户端本地转码开关/码率设置规避 |
